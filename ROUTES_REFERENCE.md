# 🌐 TJAR Authentication Routes & URLs

## 📍 Authentication Routes Reference

All routes are automatically generated by Laravel's `Auth::routes()` in your `routes/web.php` file.

---

## 🔐 Login Routes

### Show Login Form
```
GET /login
View: resources/views/auth/login.blade.php
Name: login
Description: Display the login form for user authentication
```

### Process Login
```
POST /login
Controller: App\Http\Controllers\Auth\LoginController@login
Name: login (submit)
Description: Handle user login credentials
```

### Logout
```
POST /logout
Controller: App\Http\Controllers\Auth\LoginController@logout
Name: logout
Description: Log out the authenticated user
Redirect: Usually to home or login
```

### Show Registration Form

```
GET /register

Name: register
```

```
POST /register
```

## 🔑 Password Reset Routes

### Request Password Reset
```
GET /password/reset
View: resources/views/auth/forgot-password.blade.php
Name: password.request
Description: Show password reset request form
Input: Phone/Email
```

### Send Reset Link
```
POST /password/email
Controller: App\Http\Controllers\Auth\ForgotPasswordController@sendResetLinkEmail
Name: password.email
Description: Send password reset link to user email
```

### Show Reset Form
```
GET /password/reset/{token}
View: resources/views/auth/passwords/reset.blade.php
Name: password.reset
Parameters: token (reset token)
Description: Display password reset form with token
```

### Update Password
```
POST /password/update
Controller: App\Http\Controllers\Auth\ResetPasswordController@reset
Name: password.update
Description: Update user password after token verification
```

## ✉️ Email Verification Routes

### Show Verification Notice
```
GET /email/verify
View: resources/views/auth/verify.blade.php
Name: verification.notice
Description: Prompt user to verify email
Requirement: User must be authenticated
```

### Verify Email
```
GET /email/verify/{id}/{hash}
Controller: App\Http\Controllers\Auth\VerificationController@verify
Name: verification.verify
Parameters: id, hash
Description: Mark email as verified with link from email
```

### Resend Verification Email
```
POST /email/resend
Controller: App\Http\Controllers\Auth\VerificationController@resend
Name: verification.resend
Description: Send verification link again
Requirement: User must be authenticated
```

## 🔑 Custom OTP Routes (Optional)

If you want to add OTP verification, add these to `routes/web.php`:

```php
// OTP Verification Routes
Route::middleware('auth')->group(function () {
    Route::get('/otp/verify', function () {
        return view('auth.otp-verification');
    })->name('otp.verify');
    
    Route::post('/otp/verify', [OtpController::class, 'verify'])
        ->name('otp.verify.post');
    
    Route::post('/otp/resend', [OtpController::class, 'resend'])
        ->name('otp.resend');
});
```

## 🔒 Middleware Requirements

### For Guest-Only Routes
```php
Route::middleware('guest')->group(function () {
    Route::get('/login', [LoginController::class, 'showLoginForm'])->name('login');
    Route::post('/login', [LoginController::class, 'login']);
    Route::get('/register', [RegisterController::class, 'showRegistrationForm'])->name('register');
    Route::post('/register', [RegisterController::class, 'register']);
    // Password reset routes...
});
```

### For Authenticated Routes
```php
Route::middleware('auth')->group(function () {
    Route::post('/logout', [LoginController::class, 'logout'])->name('logout');
    // Other authenticated routes...
});
```

### For Email Verification (If Required)
```php
Route::middleware(['auth', 'verified'])->group(function () {
    // Routes for verified users only
});
```

## 🔐 Route Security

### Protected Routes (Require Authentication)
```
POST /logout                    - Only authenticated users
GET  /email/verify              - Only authenticated users
POST /email/resend              - Only authenticated users
```

### Guest Routes (Block Authenticated Users)
```
GET  /login                     - Redirects if already logged in
POST /login                     - Redirects if already logged in
GET  /register                  - Redirects if already logged in
POST /register                  - Redirects if already logged in
GET  /password/reset            - Redirects if already logged in
POST /password/email            - Redirects if already logged in
GET  /password/reset/{token}    - Redirects if already logged in
```

## 📞 Troubleshooting Routes

### Route Not Found (404)
1. Ensure `Auth::routes()` is in `routes/web.php`
2. Run `php artisan route:clear`
3. Run `php artisan route:cache`

### Wrong Method (405)
1. Check form method matches route
2. Verify route definition
3. Check middleware configuration

### Redirect Loop
1. Check middleware configuration
2. Verify redirect conditions
3. Check auth guard configuration
